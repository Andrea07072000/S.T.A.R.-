Engineering assessment

An independent check of a defined calculation, with a written scope and a report you can rerun.

01

Verify

Check a defined result against mathematical expectations, published reference values or a reference implementation.

02

Crosscheck

Run independent libraries on the same cases and record versions, input normalisation, residuals and shared dependencies.

03

Assess

Document limits, discrepancies, failure modes and reproducibility gaps, with the next steps that would close them.

What you receive

  • A comparison of your function with at least two independent implementations, on cases chosen to reach its limits: singular geometries, extreme values, malformed input.
  • The residuals, the tolerance and the versions of everything that was run.
  • The cases where it fails, refuses or silently accepts bad input.
  • The test cases and evidence files, yours to keep and rerun.
  • A plain statement of what was not tested.

What it is not

  • Not a certification or a qualification for flight.
  • Not a guarantee that the software has no defects.
  • Not an automated service: every assessment is scoped and carried out by a person.

Domains we can assess today

Orbit propagation and Kepler problems · Lambert and manoeuvres · orbital elements and anomalies · time scales (UTC, TAI, TT, TDB, sidereal time) · reference frames and geodesy · attitude (quaternions, MRP, Euler, Wahba) · CCSDS packets, frames and time codes · numerical methods.

Price

Quoted per scope, in writing, before any work starts. Nothing is charged for the first exchange.

How a result becomes evidence

  1. Define the scope and units
  2. Validate the inputs
  3. Record versions and provenance
  4. Run the permitted tools
  5. Compare with references
  6. Investigate discrepancies
  7. Write the evidence
  8. Report the limitations
