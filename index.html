The problem

Have an engineering result you need to trust?

A propagator step, a time-scale conversion, a telemetry decoder, an attitude routine: S.T.A.R. checks a defined calculation within an agreed scope — against independent implementations, published values and hostile inputs — and reports what agrees, what does not and what was not tested.

01

Verify

Check a defined result against mathematical expectations, published reference values or a reference implementation.

02

Crosscheck

Run independent libraries on the same cases and record versions, input normalisation, residuals and shared dependencies.

03

Assess

Document limits, discrepancies, failure modes and reproducibility gaps, with the next steps that would close them.

How a result becomes evidence

  1. Define the scope and units
  2. Validate the inputs
  3. Record versions and provenance
  4. Run the permitted tools
  5. Compare with references
  6. Investigate discrepancies
  7. Write the evidence
  8. Report the limitations
