User guides

Using the Workspace

Select a task, enter or upload your data, then select Run. The first run downloads the engine once (about 12 MB). Nothing you enter or upload leaves your computer; closing the tab erases it. Processing runs in the background, so the page remains responsive even with a large file; Stop ends a run.

Reading a verification receipt

1. which S.T.A.R. software performed the work, with its version; 2. the input provided, with its SHA-256 fingerprint (the same input always yields the same fingerprint); 3. every change applied to the input before use; 4. the checks performed, each passed or failed; 5. the limits, and any item requiring human review. Keep it with the result, or attach it to a report.

Labels on visuals and results

Teaching illustration: explains a concept; not computed from data. Numerical simulation: computed by a stated model. Real software benchmark: measured by running S.T.A.R. software on stated data and hardware. Real hardware measurement: measured on a physical device.

RELEASED and VERIFIED

RELEASED: installed from a fixed version, tests pass, compared with independent implementations, and a mutation test shows that the tests detect deliberately introduced errors (score of at least 0.85). VERIFIED: tested and compared, but at least one release gate is not yet met.
