From a copy of the public repository:

git clone https://github.com/Andrea07072000/S.T.A.R.-.git
cd S.T.A.R.-/packages/star_crosscheck
python -m pip install -e .
star-xc run campaigns/xc008_orbit_propagation.py

Clean-install test

On 2026-10-08 every public package was installed in its own fresh Linux virtual environment and its tests were run: 70 packages, 4388 tests passed.

What “released” means

A capability is RELEASED when it is installed from a fixed version, its tests pass, and it agrees with at least one independent implementation besides ours. Where mutation testing has been run on its tests, the score is listed in the package evidence. Today: 90 released.
