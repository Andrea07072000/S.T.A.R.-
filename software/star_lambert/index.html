Orbits & astrodynamics

star-lambert 0.1.3

Universal-variable Lambert orbital boundary value problem solver

Apache-2.0 RELEASED single file

In plain words

Zero-revolution solver for Lambert's problem (universal variables, Stumpff functions, Newton on z; Bate-Mueller-White / Curtis Algorithm 5.2). Standard library only.

Try it here

Edit the code and press Run (or Ctrl+Enter). Python runs in your browser with this package's published code. The first run downloads Python once (about 12 MB).

Use it on your computer

No account and no GitHub needed. Download, then install with one command:

  • Install file · star_lambert-0.1.3-py3-none-any.whl 3 kB
  • Single file — just copy it next to your code · star_lambert.py 5 kB
  • Source code (.zip) 23 kB
python -m pip install star_lambert-0.1.3-py3-none-any.whl
