star-telemetry 0.2.7

CCSDS AOS/TM transfer frame deframer and Space Packet reassembler

Apache-2.0 RELEASED

In plain words

CCSDS AOS v2 / TM v1 transfer-frame deframer and Space Packet reassembler, with CUC time decoding via star-timescales.

Try it here

Edit the code and press Run (or Ctrl+Enter). Python runs in your browser with this package's published code. The first run downloads Python once (about 12 MB).

Runs in the browser: 92 of 93 tests pass in the browser's Python (Pyodide 314.0.7, Python 3.14.2), measured on 20 October 2026. The other test starts a separate program or needs an outside reference library, which a browser cannot do.

Requirements

  • R1 CcsdsTransferFrameEngine(frame_length, has_fecf).parse_frame(bytes) -> (header, data_field): TFVN, SCID, VCID, VC frame count, replay flag, first header pointer, FECF (CRC-16, poly 0x1021, init 0xFFFF) validity.
  • R2 process_raw_stream(bytes) reassembles Space Packets across frames per virtual channel, including spanning packets. A packet is delivered in the frame that completes it. After a lost frame, the rest of the interrupted packet is discarded up to the next first header pointer. A pending packet whose size disagrees with its declared length is dropped, never cut to size.
  • R3 A frame of the wrong length is rejected with ValueError; a corrupted frame is reported (fecf_valid = False), never silently accepted.

Limits (what is not claimed)

TC frames, USLP, frame synchronisation/ASM search, Reed-Solomon, the F Prime flight AosFramer component as oracle (test harness only), any flight qualification.
