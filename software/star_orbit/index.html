Orbits & astrodynamics

star-orbit 0.2.2

Numerical orbit propagation (Cowell, fixed-step RK4) with two-body + J2 gravity, linked to star_timescales

Public state: Beta. The registry label is VERIFIED. What the states mean →

Apache-2.0 Beta

Summary

Cowell numerical orbit propagation (fixed-step RK4) with two-body + J2 gravity, federated with star-timescales for epochs.

Run in your browser

Edit the code and press Run (or Ctrl+Enter). Python runs in your browser with this package's published code. The first run downloads Python once (about 12 MB).

Runs in the browser: all 40 tests pass in the browser's Python (Pyodide 314.0.7, Python 3.14.2), measured on 20 October 2026. 1 test skipped there: it needs something not available in a browser (an outside reference program or an extra not yet published). A browser has no threads, so the time limits of its contract tests are not checked there; their results are.

Use it on your computer

No account and no GitHub needed. Download, then install with one command:

  • Install file · star_orbit-0.2.2-py3-none-any.whl 11 kB
  • Source code (.zip) 28 kB

Download also: star-timescales (install them together).

python -m pip install star_timescales-0.2.0-py3-none-any.whl star_orbit-0.2.2-py3-none-any.whl

In Python: import star_orbit

Limits (what is not claimed)
