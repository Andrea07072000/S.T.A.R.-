Orbits & astrodynamics

star-orbit 0.2.2

Cowell high-fidelity numerical perturbation orbit propagator federated with star_timescales

Apache-2.0 RELEASED

In plain words

Cowell numerical orbit propagation (fixed-step RK4) with two-body + J2 gravity, federated with star-timescales for epochs.

Try it here

Edit the code and press Run (or Ctrl+Enter). Python runs in your browser with this package's published code. The first run downloads Python once (about 12 MB).

Use it on your computer

No account and no GitHub needed. Download, then install with one command:

  • Install file · star_orbit-0.2.2-py3-none-any.whl 11 kB
  • Source code (.zip) 28 kB

Download also: star-timescales (install them together).

python -m pip install star_timescales-0.2.0-py3-none-any.whl star_orbit-0.2.2-py3-none-any.whl
