1. Controller

Andrea Cavazzini, private individual, Italy. Contact for every privacy matter: Info.and.News.S.T.A.R@proton.me. No data protection officer has been appointed, because none is required for this activity.

2. What this website does not do

No cookies, no analytics, no advertising or tracking pixels, no fingerprinting, no forms that store data, no accounts, no local storage. Fonts and scripts are served from the same website, not from third-party services.

When you press Run on a package page, Python (Pyodide) is downloaded from this same website and runs entirely in your browser: the code you write and its results never leave your device.

3. Data processed when you visit

When a page is requested, the hosting provider's servers necessarily process technical data: IP address, date and time, requested address, browser identification string. These data are used only to deliver the pages and to protect the service against abuse (legitimate interest, Art. 6(1)(f) GDPR). The owner does not use them to identify visitors. The website is hosted by GitHub, Inc. (GitHub Pages), which processes these data under its own privacy statement; GitHub is based in the United States, so these data may be processed there; the safeguards it applies to such transfers (Art. 44-49 GDPR) are described in that statement. For these logs GitHub decides how they are kept and used, so it acts as an independent controller, not on the owner's instructions. See infrastructure and providers.

4. Data you send by email

If you write to the contact address, the owner receives your address, your name if you give it, and the content of the message. They are used to answer you and, if you ask for it, to prepare a proposal (pre-contractual measures, Art. 6(1)(b) GDPR). Emails are kept as long as the correspondence is useful and in any case no longer than 24 months after the last message, unless a contract requires longer retention for legal reasons. The mailbox is provided by Proton AG (Switzerland, a country with an adequacy decision of the European Commission).

Please do not send confidential, export-controlled or personal data of others in a first message: confidentiality is agreed before any such material is exchanged.

5. Who receives the data

Only the owner, and the providers named above, each for its own part of the technical service (Proton as the owner's mail provider; GitHub as described in section 3). Data are not sold or shared for marketing.

6. Your rights

You may ask for access, rectification, erasure, restriction, portability and object to processing (Art. 15–22 GDPR) by writing to the contact address. You may lodge a complaint with the Italian supervisory authority, the Garante per la protezione dei dati personali.

7. Changes

If the website starts using any additional processing (for example aggregated statistics), this notice is updated before the change takes effect.
