5. What it does, and its limits

Classical orbital elements to and from Cartesian state. Standard library only.

  • rv_to_coe(r, v, mu=398600.4418) -> (h, e, i, raan, argp, nu) (Curtis Algorithm 4.2); units km, km/s, radians.
  • coe_to_rv(h, e, i, raan, argp, nu, mu) -> (r, v) (Curtis Algorithm 4.5).
  • Singular or invalid cases raise ValueError: equatorial (no RAAN), circular (no argp), rectilinear, h <= 0, hyperbolic true anomaly beyond the asymptotes. No arbitrary angle is ever returned for an undefined element.
  • (0.2.0) Anomalies for 0 <= e < 1: mean_to_eccentric (Kepler, Newton; RuntimeError if not converged), eccentric_to_true, true_to_eccentric, eccentric_to_mean; e >= 1 raises ValueError.
