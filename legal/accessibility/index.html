Target: WCAG 2.2 level AA. This is a design target, not a certified conformance: no independent audit has been carried out yet.

What was done

  • Semantic HTML, one main heading per page, a link to skip to the content.
  • Every function is usable with the keyboard; focus is always visible.
  • Status is never shown by colour alone; it always has a text label.
  • The 3D view has a 2D projection and a table with the same numbers; motion is stopped when your system asks for reduced motion.
  • Pages reflow on small screens and zoom to 200%.

Known limits

  • The 3D view itself cannot be explored with a screen reader; use the table tab, which contains every value.
  • Some technical package descriptions use specialist terms.

To report a barrier: Info.and.News.S.T.A.R@proton.me (subject ACCESSIBILITY).
