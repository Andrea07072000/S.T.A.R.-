Vulnerability disclosure policy

How to report a security problem in the website or the S.T.A.R. software.

Write to Info.and.News.S.T.A.R@proton.me with the subject SECURITY: what you found, how to reproduce it, and the version or address affected. Please do not include personal data of others.

What to expect

  • An acknowledgement within 7 days.
  • An assessment and, if confirmed, a fix plan; you are told when the fix is published.
  • Credit in the correction note if you want it.

Scope and good faith

In scope: this website and the packages in the public repository. Please do not run denial-of-service tests, do not access data that is not yours and give reasonable time for a fix before public disclosure. Research done in good faith within these limits will not be the subject of complaints by the owner.

The website is static: it has no accounts, no forms that store data and no server-side code of its own. A machine-readable contact is published at /.well-known/security.txt (RFC 9116).
