1. Everything comes from this website

Pages, fonts, scripts, images, the Python runtime used by "Try it here" and the downloadable files are all served from this website's own address, which the hosting provider (GitHub Pages) delivers through its own servers and content delivery network. Your browser does not contact Google, font services, analytics services, advertising networks or any other third-party service while you read it.

2. Fonts in particular

The fonts (Space Grotesk, Inter, JetBrains Mono, under the SIL Open Font License) are copies stored on this website. They are not loaded from Google Fonts: loading fonts from a third-party server transmits the visitor's IP address to that server, and a German court held that doing so without consent breaches the GDPR (Landgericht München I, 20 January 2022, 3 O 17493/20). This website avoids the question by not doing it.

3. When a third party is contacted

  • Only when you click a link that leads elsewhere (for example the source code on GitHub, or an authority's website).
  • Only when you choose to write an email: your mail program contacts your mail provider and the owner's (Proton).

4. How to check it yourself

Open your browser's developer tools, tab "Network", and reload any page: every request goes to the same address as the page. The owner's automatic tests check the same thing before every publication.
