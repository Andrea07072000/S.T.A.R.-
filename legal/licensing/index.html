S.T.A.R. packages

Every package in the public repository is distributed under the Apache License 2.0. The licence of each package is stated in its pyproject.toml; the repository contains the full licence text.

Third-party libraries used for comparison

Cross-checks compare S.T.A.R. with other libraries (for example SciPy, Basilisk, Orekit, Skyfield, Astropy, SPICE). They are run separately, are not distributed with S.T.A.R. packages and remain under their own licences. Packages that need a third-party library at run time list it as a dependency; it is installed from its own source under its own licence.
