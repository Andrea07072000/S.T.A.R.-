Use it on your computer, step by step

  1. Install Python
    If you do not have it: download Python 3.9 or later from python.org (Windows: tick “Add python.exe to PATH” during installation). macOS and most Linux systems already have it.
  2. Download the package
    On the package page, under “Use it on your computer”, download the .whl file (or the whole collection from Downloads).
  3. Open a terminal in the download folder
    Windows: in the folder, type cmd in the address bar and press Enter. macOS: right-click the folder → New Terminal at Folder. Linux: right-click → Open in Terminal.
  4. Install
    Type: python -m pip install <the file you downloaded>.whl — for example python -m pip install star_kepler-0.1.1-py3-none-any.whl
  5. Use it
    Start python and import the package, as in the example on its page.

Without installing anything

Packages made of one file with no dependencies (marked “single file”) can be used by downloading that .py file and putting it in the same folder as your own script. It then works with import, like any of your files.

Other machines and build environments

The wheels are pure Python (py3-none-any): the same file installs on any operating system and processor. For an air-gapped machine, copy the collection archive and install with --no-index. For your own build system or packaging, use the source .zip of each package. Every file has a published SHA-256 fingerprint.
