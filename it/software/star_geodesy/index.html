Geodesia e mappe

star-geodesy 0.1.1

Coordinate geodetiche WGS-84 da/verso ECEF, con inversione esatta a qualunque quota

Apache-2.0 VERIFIED file singolo

Sintesi

Coordinate geodetiche WGS-84 da e verso ECEF. Solo libreria standard.

Esegui nel browser

Modifica il codice e premi Esegui (o Ctrl+Invio). Python gira nel tuo browser con il codice pubblicato di questo pacchetto. La prima volta scarica Python una sola volta (circa 12 MB).

Funziona nel browser: tutti i 19 test passano nel Python del browser (Pyodide 314.0.7, Python 3.14.2), misurato il 20 ottobre 2026.

Usalo sul tuo computer

Non servono account né GitHub. Scarica, poi installa con un comando:

  • File di installazione · star_geodesy-0.1.1-py3-none-any.whl 2 kB
  • File singolo — da copiare accanto al tuo codice · star_geodesy.py 2 kB
  • Codice sorgente (.zip) 11 kB
python -m pip install star_geodesy-0.1.1-py3-none-any.whl

Requisiti

  • R1 geodetic_to_ecef(lat_deg, lon_deg, h_m) -> (x, y, z) in metri (costanti WGS-84, NIMA TR8350.2).
  • R2 ecef_to_geodetic(x, y, z) -> (lat_deg, lon_deg, h_m), iterativa fino a 1e-14 rad a QUALUNQUE quota; RuntimeError se non converge; la trasformazione diretta del risultato si chiude entro meno di 1 micrometro.
  • R3 Gli ingressi non validi sollevano ValueError (|lat| > 90, centro della Terra).

Limiti (che cosa non si afferma)

Altri datum, altezze del geoide, distanze geodetiche (vedi XC-003), qualsiasi uso in volo.
