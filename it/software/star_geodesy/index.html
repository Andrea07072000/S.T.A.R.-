Geodesia e mappe

star-geodesy 0.1.1

WGS-84 geodetic to/from ECEF with exact inversion at any altitude

Apache-2.0 RELEASED file singolo

La documentazione tecnica del pacchetto è in inglese, come il suo codice.

In parole semplici

WGS-84 geodetic coordinates to and from ECEF. Standard library only.

Provalo qui

Modifica il codice e premi Esegui (o Ctrl+Invio). Python gira nel tuo browser con il codice pubblicato di questo pacchetto. La prima volta scarica Python una sola volta (circa 12 MB).

Usalo sul tuo computer

Non servono account né GitHub. Scarica, poi installa con un comando:

  • File di installazione · star_geodesy-0.1.1-py3-none-any.whl 2 kB
  • File singolo — basta copiarlo accanto al tuo codice · star_geodesy.py 2 kB
  • Codice sorgente (.zip) 11 kB
python -m pip install star_geodesy-0.1.1-py3-none-any.whl

Requisiti

  • R1 geodetic_to_ecef(lat_deg, lon_deg, h_m) -> (x, y, z) in metres (WGS-84, NIMA TR8350.2 constants).
  • R2 ecef_to_geodetic(x, y, z) -> (lat_deg, lon_deg, h_m), iterative to 1e-14 rad at ANY altitude; RuntimeError if it does not converge; the forward transform of the result closes to < 1 micrometre.
  • R3 Invalid input raises ValueError (|lat| > 90, Earth's centre).
