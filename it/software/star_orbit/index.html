Orbite e astrodinamica

star-orbit 0.2.2

Propagazione orbitale numerica (Cowell, RK4 a passo fisso) con gravità a due corpi + J2, collegata a star_timescales

Apache-2.0 VERIFIED

Sintesi

Propagazione orbitale numerica di Cowell (RK4 a passo fisso) con gravità a due corpi + J2, collegata a star-timescales per le epoche.

Esegui nel browser

Modifica il codice e premi Esegui (o Ctrl+Invio). Python gira nel tuo browser con il codice pubblicato di questo pacchetto. La prima volta scarica Python una sola volta (circa 12 MB).

Funziona nel browser: tutti i 40 test passano nel Python del browser (Pyodide 314.0.7, Python 3.14.2), misurato il 20 ottobre 2026. 1 test saltato lì: richiede qualcosa che in un browser non c'è (un programma di riferimento esterno o un'estensione non ancora pubblicata). Un browser non ha thread, quindi lì non si controllano i limiti di tempo dei suoi test di contratto; i risultati sì.

Usalo sul tuo computer

Non servono account né GitHub. Scarica, poi installa con un comando:

  • File di installazione · star_orbit-0.2.2-py3-none-any.whl 11 kB
  • Codice sorgente (.zip) 28 kB

Scarica anche: star-timescales (installali insieme).

python -m pip install star_timescales-0.2.0-py3-none-any.whl star_orbit-0.2.2-py3-none-any.whl

Requisiti

  • R1 propagate_orbit(OrbitState, duration_sec, step_sec, include_j2=True, ...) -> list[OrbitState], unità SI (m, s, m/s), mu = 3,986004418e14 m^3/s^2, Re = 6378137 m, J2 = 1,08262668e-3 (WGS-84 / EGM96).
  • R2 Richiedere una forza non disponibile (resistenza/pressione di radiazione senza star-weather) solleva RuntimeError; una forza non viene mai omessa in silenzio.

Limiti (che cosa non si afferma)

Resistenza atmosferica e pressione di radiazione solare nel pacchetto rilasciato, geopotenziale di ordine superiore, terzi corpi, confronto con una traiettoria di riferimento pubblicata, qualsiasi uso operativo o in volo.
