Orbite e astrodinamica

star-orbit 0.2.2

Cowell high-fidelity numerical perturbation orbit propagator federated with star_timescales

Apache-2.0 RELEASED

La documentazione tecnica del pacchetto è in inglese, come il suo codice.

In parole semplici

Cowell numerical orbit propagation (fixed-step RK4) with two-body + J2 gravity, federated with star-timescales for epochs.

Provalo qui

Modifica il codice e premi Esegui (o Ctrl+Invio). Python gira nel tuo browser con il codice pubblicato di questo pacchetto. La prima volta scarica Python una sola volta (circa 12 MB).

Usalo sul tuo computer

Non servono account né GitHub. Scarica, poi installa con un comando:

  • File di installazione · star_orbit-0.2.2-py3-none-any.whl 11 kB
  • Codice sorgente (.zip) 28 kB

Scarica anche: star-timescales (installali insieme).

python -m pip install star_timescales-0.2.0-py3-none-any.whl star_orbit-0.2.2-py3-none-any.whl
