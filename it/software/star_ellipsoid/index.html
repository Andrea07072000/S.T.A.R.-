Geodesia e mappe

star-ellipsoid 0.1.0

L'ellissoide WGS-84 come superficie

Apache-2.0 RELEASED file singolo

In parole semplici

Raggi di curvatura, raggio geocentrico, latitudine geocentrica / parametrica / rettificante e arco di meridiano sul WGS-84 a una latitudine geodetica; concorda con pymap3d e PyGeodesy all'arrotondamento (arco entro 4e-9 m) e rifiuta latitudini fuori da [-90, 90].

Provalo qui

Modifica il codice e premi Esegui (o Ctrl+Invio). Python gira nel tuo browser con il codice pubblicato di questo pacchetto. La prima volta scarica Python una sola volta (circa 12 MB).

Usalo sul tuo computer

Non servono account né GitHub. Scarica, poi installa con un comando:

  • File di installazione · star_ellipsoid-0.1.0-py3-none-any.whl 3 kB
  • File singolo — basta copiarlo accanto al tuo codice · star_ellipsoid.py 4 kB

python -m pip install star_ellipsoid-0.1.0-py3-none-any.whl

Requisiti

  • R1 meridian_radius, prime_vertical_radius, gaussian_radius, geocentric_radius (metri) a una latitudine geodetica in gradi; costanti WGS-84 come pubblicate.
  • R2 geocentric_latitude, parametric_latitude, rectifying_latitude (gradi); meridian_arc (metri dall'equatore, negativi a sud; serie di Helmert fino a n^5) e MERIDIAN_QUADRANT = 10 001 965,729 m.
  • R3 Misurato su 505 latitudini contro pymap3d e PyGeodesy: raggi entro 5e-16 relativo, latitudini ausiliarie entro 5e-14 gradi, arco di meridiano entro 4e-9 m.
  • R4 Ogni funzione restituisce un float finito o solleva ValueError: ingressi non numerici, booleani, NaN o infiniti, e qualunque latitudine fuori da [-90, 90] (non ricondotta nell'intervallo).

Limiti (che cosa non si afferma)

L'ellissoide, non la Terra: niente geoide, nessuna quota del terreno. Solo WGS-84 (GRS80 differisce alla decima cifra di f).
