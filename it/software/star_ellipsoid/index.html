Geodesia e mappe

star-ellipsoid 0.1.0

The WGS-84 ellipsoid as a surface

Apache-2.0 RELEASED file singolo

La documentazione tecnica del pacchetto è in inglese, come il suo codice.

In parole semplici

Radii of curvature, geocentric radius, geocentric / parametric / rectifying latitude and meridian arc on WGS-84 at a geodetic latitude; agrees with pymap3d and PyGeodesy to rounding (arc within 4e-9 m) and refuses latitudes outside [-90, 90].

Provalo qui

Modifica il codice e premi Esegui (o Ctrl+Invio). Python gira nel tuo browser con il codice pubblicato di questo pacchetto. La prima volta scarica Python una sola volta (circa 12 MB).

Usalo sul tuo computer

Non servono account né GitHub. Scarica, poi installa con un comando:

  • File di installazione · star_ellipsoid-0.1.0-py3-none-any.whl 3 kB
  • File singolo — basta copiarlo accanto al tuo codice · star_ellipsoid.py 4 kB

python -m pip install star_ellipsoid-0.1.0-py3-none-any.whl

Requisiti

  • R1 meridian_radius, prime_vertical_radius, gaussian_radius, geocentric_radius (metres) at a geodetic latitude in degrees; WGS-84 constants as published.
  • R2 geocentric_latitude, parametric_latitude, rectifying_latitude (degrees); meridian_arc (metres from the equator, negative in the south; Helmert's series to n^5) and MERIDIAN_QUADRANT = 10 001 965.729 m.
  • R3 Measured on 505 latitudes against pymap3d and PyGeodesy: radii within 5e-16 relative, auxiliary latitudes within 5e-14 deg, meridian arc within 4e-9 m.
  • R4 Every function returns a finite float or raises ValueError: non-numeric, boolean, NaN or infinite input, and any latitude outside [-90, 90] (not wrapped).

Limiti (che cosa non si afferma)

The ellipsoid, not the Earth: no geoid, no terrain height. WGS-84 only (GRS80 differs in the tenth digit of f).
