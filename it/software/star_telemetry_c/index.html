star-aos-c 0.1.3

Controllo dei transfer frame CCSDS AOS/TM in C99 (S.T.A.R.)

Apache-2.0 RELEASED

In parole semplici

Decodifica dell'intestazione primaria CCSDS AOS v2 / TM v1 e controllo CRC-16 del FECF in C99, con risultati identici verificati su 18 architetture emulate e 12 microcontrollori / processori spaziali simulati, confronto incrociato con spacepackets, fuzzing e mutation testing.

Provalo qui

Modifica il codice e premi Esegui (o Ctrl+Invio). Python gira nel tuo browser con il codice pubblicato di questo pacchetto. La prima volta scarica Python una sola volta (circa 12 MB).

Requisiti

  • R1 star_aos_parse(frame, len, has_fecf, &hdr): TFVN, SCID, VCID, contatore di frame del canale virtuale, replay (AOS), FHP; TM: contatore del canale virtuale dall'ottetto 3, flag OCF (4 ottetti prima del FECF), intestazione secondaria saltata (lunghezza dal suo ottetto ID).
  • R2 FECF: CRC-16/CCITT-FALSE sul frame senza il FECF; fecf_valid solo quando calcolato == ricevuto.
  • R3 Formato esatto: data_offset + data_len + ocf_len (+2 with FECF) == len; offset dei dati TM 6 oppure 7 + (ID & 0x3F).
  • R4 Errori: ingressi NULL -> STAR_AOS_ERR_NULL; frame troppo corti per il formato dichiarato -> STAR_AOS_ERR_SHORT; mai una lettura fuori da [frame, frame + len).
  • R5 Portabilità: risultati identici su ogni piattaforma elencata sotto (lettura byte per byte, nessun comportamento indefinito).
