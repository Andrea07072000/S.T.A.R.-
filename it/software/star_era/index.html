Tempo e rotazione terrestre

star-era 0.1.2

Angolo di rotazione terrestre e tempo siderale IAU 2006

Apache-2.0 RELEASED file singolo

In parole semplici

Angolo di rotazione terrestre (ERA) e tempo siderale medio di Greenwich IAU 2006 da date giuliane in due parti nel periodo 1800-2200; riproduce i valori di validazione SOFA entro 1e-13 rad e concorda con ERFA e Skyfield entro 4e-8 secondi d'arco.

Provalo qui

Modifica il codice e premi Esegui (o Ctrl+Invio). Python gira nel tuo browser con il codice pubblicato di questo pacchetto. La prima volta scarica Python una sola volta (circa 12 MB).

Usalo sul tuo computer

Non servono account né GitHub. Scarica, poi installa con un comando:

  • File di installazione · star_era-0.1.2-py3-none-any.whl 3 kB
  • File singolo — basta copiarlo accanto al tuo codice · star_era.py 3 kB
  • Codice sorgente (.zip) 17 kB
python -m pip install star_era-0.1.2-py3-none-any.whl

Requisiti

  • R1 era_deg(ut1_day, ut1_frac=0): ERA in gradi in [0, 360), IERS Conventions (2010) eq. 5.15. Riproduce il valore di validazione SOFA entro 1e-13 rad.
  • R2 gmst06_deg(ut1_day, ut1_frac, tt_day, tt_frac): ERA più il polinomio IAU 2006 in TT (eq. 5.32). Riproduce il valore di validazione SOFA entro 1e-13 rad.
  • R3 Le date sono date giuliane in due parti (qualunque suddivisione); un nanosecondo di UT1 resta visibile. Misurato su 1000 date nel periodo 1800-2200: entro 2,4e-8 secondi d'arco da ERFA (ERA e GMST) ed entro 3,6e-8 secondi d'arco da Skyfield (ERA).
  • R4 Ogni funzione restituisce un angolo finito in [0, 360) o solleva ValueError: ingressi non numerici, booleani, NaN o infiniti, una data fuori dall'intervallo 1800-01-01 – 2200-01-01.

Limiti (che cosa non si afferma)

Solo tempo siderale medio: niente equazione degli equinozi (tempo siderale apparente), niente moto del polo, e UT1 è un dato in ingresso (UT1 - UTC viene dall'IERS, non da qui). Per il modello GMST 1982 vedi star_sidereal.
