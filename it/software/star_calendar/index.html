star-calendar 0.1.0

Date di calendario e numeri del giorno giuliano, in modo esatto

Apache-2.0 RELEASED file singolo

In parole semplici

Conversione esatta, in numeri interi, tra date di calendario e numeri del giorno giuliano nei calendari giuliano, gregoriano prolettico e civile, dal JDN 0 all'anno 9999; identica a ERFA, al datetime di CPython e a NAIF SPICE su 9014 date, e le date che non esistono sono rifiutate.

Provalo qui

Modifica il codice e premi Esegui (o Ctrl+Invio). Python gira nel tuo browser con il codice pubblicato di questo pacchetto. La prima volta scarica Python una sola volta (circa 12 MB).

Usalo sul tuo computer

Non servono account né GitHub. Scarica, poi installa con un comando:

  • File di installazione · star_calendar-0.1.0-py3-none-any.whl 3 kB
  • File singolo — basta copiarlo accanto al tuo codice · star_calendar.py 6 kB
  • Codice sorgente (.zip) 18 kB
python -m pip install star_calendar-0.1.0-py3-none-any.whl

Requisiti

  • R1 jdn(year, month, day, calendar) e calendar_date(jdn, calendar) per "gregorian", "julian" e "auto" (giuliano fino al 1582-10-04, gregoriano dal 1582-10-15); numerazione astronomica degli anni; valido dal JDN 0 al 9999-12-31.
  • R2 julian_date(...) restituisce la coppia (JD alla mezzanotte precedente, frazione di giorno): la somma è la data giuliana e la coppia conserva un nanosecondo che un singolo float perderebbe. weekday(jdn) (0 = lunedì), day_of_year(...).
  • R3 Misurato: lo stesso numero del giorno di ERFA, del datetime di CPython e di NAIF SPICE (calendario MIXED) su 9014 date, zero discordanze, inclusi gli anni avanti Cristo e ogni giorno attorno al passaggio del 1582.
  • R4 Ogni funzione restituisce interi (o la coppia documentata) o solleva ValueError: anno, mese, giorno o numero del giorno non interi o booleani; una data che non esiste nel calendario (29 febbraio 1900 gregoriano, dal 1582-10-05 al 1582-10-14 civile); un calendario sconosciuto; un'ora fuori dal giorno; qualunque valore fuori dall'intervallo valido.

Limiti (che cosa non si afferma)

Un calendario, non una scala di tempo: niente secondi intercalari, nessuna conversione UTC/TT/TDB, niente fusi orari, nessuna data locale di adozione del calendario gregoriano (il passaggio civile è quello papale dell'ottobre 1582).
