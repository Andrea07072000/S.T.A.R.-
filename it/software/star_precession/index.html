star-precession 0.1.0

Tra J2000 e l'equatore medio della data (IAU 1976)

Apache-2.0 RELEASED file singolo

In parole semplici

Matrice di precessione IAU 1976 e rotazioni di vettori tra J2000 e l'equatore e l'equinozio medi della data nel periodo 1800-2200; uguale a pmat76 di ERFA entro 1,2e-16 ed entro 0,21 secondi d'arco dalla precessione propria di PyEphem.

Provalo qui

Modifica il codice e premi Esegui (o Ctrl+Invio). Python gira nel tuo browser con il codice pubblicato di questo pacchetto. La prima volta scarica Python una sola volta (circa 12 MB).

Usalo sul tuo computer

Non servono account né GitHub. Scarica, poi installa con un comando:

  • File singolo — basta copiarlo accanto al tuo codice · star_precession.py 4 kB

python -m pip install star_precession-0.1.0-py3-none-any.whl

Requisiti

  • R1 precession_matrix(jd_day, jd_frac=0): P = R3(-z) R2(theta) R3(-zeta) con gli angoli di Lieske (1979); identità a J2000.0. Riproduce i valori di validazione SOFA di pmat76 entro 1e-15.
  • R2 mod_from_j2000(r, ...), j2000_from_mod(r, ...) (la trasposta) e precession_angles_arcsec.
  • R3 Misurato su 500 date nel periodo 1800-2200: ogni elemento della matrice entro 1,2e-16 da ERFA; 1500 direzioni entro 0,21 secondi d'arco da PyEphem, che ha un proprio codice di precessione.
  • R4 Ogni funzione restituisce float finiti o solleva ValueError: ingressi non numerici, booleani, NaN o infiniti, un vettore che non è di tre numeri finiti, una data fuori dall'intervallo 1800-01-01 – 2200-01-01.

Limiti (che cosa non si afferma)

Solo IAU 1976: non la precessione IAU 2006 (differiscono di circa 0,3 secondi d'arco per secolo), niente nutazione (fino a 17 secondi d'arco), nessun bias di sistema tra J2000 e GCRF (17 millesimi di secondo d'arco). Sufficiente per vettori noti al centesimo di grado; non per l'astrometria al secondo d'arco.
