star-lambert 0.1.3

Risolutore del problema di Lambert con variabili universali

Apache-2.0 RELEASED file singolo

In parole semplici

Risolutore a zero rivoluzioni del problema di Lambert (variabili universali, funzioni di Stumpff, Newton su z; Bate-Mueller-White / algoritmo 5.2 di Curtis). Solo libreria standard.

Provalo qui

Modifica il codice e premi Esegui (o Ctrl+Invio). Python gira nel tuo browser con il codice pubblicato di questo pacchetto. La prima volta scarica Python una sola volta (circa 12 MB).

Usalo sul tuo computer

Non servono account né GitHub. Scarica, poi installa con un comando:

  • File di installazione · star_lambert-0.1.3-py3-none-any.whl 3 kB
  • File singolo — basta copiarlo accanto al tuo codice · star_lambert.py 5 kB
  • Codice sorgente (.zip) 23 kB
python -m pip install star_lambert-0.1.3-py3-none-any.whl

Requisiti

  • R1 lambert(r1, r2, tof, mu=398600.4418, prograde=True) -> (v1, v2): velocità in r1 e r2 per un trasferimento di durata tof. Unità: km, s, km/s, km^3/s^2.

  • R3 Gli ingressi non validi falliscono esplicitamente: ValueError per tof <= 0, vettori posizione nulli, geometria degenere (0 o 180 gradi).
