star-tdb 0.1.1

TDB - TT with the USNO Circular 179 series, verified against ERFA full series within 10 microseconds

Apache-2.0 RELEASED file singolo

La documentazione tecnica del pacchetto è in inglese, come il suo codice.

In parole semplici

TDB - TT for a TT Julian date, geocentre. Standard library only.

Provalo qui

Modifica il codice e premi Esegui (o Ctrl+Invio). Python gira nel tuo browser con il codice pubblicato di questo pacchetto. La prima volta scarica Python una sola volta (circa 12 MB).

Usalo sul tuo computer

Non servono account né GitHub. Scarica, poi installa con un comando:

  • File di installazione · star_tdb-0.1.1-py3-none-any.whl 2 kB
  • File singolo — basta copiarlo accanto al tuo codice · star_tdb.py 1 kB
  • Codice sorgente (.zip) 11 kB
python -m pip install star_tdb-0.1.1-py3-none-any.whl

Requisiti

  • R1 tdb_minus_tt(jd_tt) -> seconds, USNO Circular 179 (Kaplan 2005) eq. 2.6, 7 terms.
  • R2 Accuracy within 10 microseconds of the full Fairhead & Bretagnon series over 1600-2200.
  • R3 Outside 1600-2200 raises ValueError (no extrapolation beyond stated validity).
