star-tdb 0.1.1

TDB - TT con la serie della USNO Circular 179, verificato con la serie completa di ERFA entro 10 microsecondi

Apache-2.0 VERIFIED file singolo

Sintesi

TDB - TT per una data giuliana TT, al geocentro. Solo libreria standard.

Esegui nel browser

Modifica il codice e premi Esegui (o Ctrl+Invio). Python gira nel tuo browser con il codice pubblicato di questo pacchetto. La prima volta scarica Python una sola volta (circa 12 MB).

Funziona nel browser: tutti i 13 test passano nel Python del browser (Pyodide 314.0.7, Python 3.14.2), misurato il 20 ottobre 2026.

Usalo sul tuo computer

Non servono account né GitHub. Scarica, poi installa con un comando:

  • File di installazione · star_tdb-0.1.1-py3-none-any.whl 2 kB
  • File singolo — da copiare accanto al tuo codice · star_tdb.py 1 kB
  • Codice sorgente (.zip) 11 kB
python -m pip install star_tdb-0.1.1-py3-none-any.whl

Requisiti

  • R1 tdb_minus_tt(jd_tt) -> seconds (secondi), USNO Circular 179 (Kaplan 2005) eq. 2.6, 7 termini.
  • R2 Accuratezza entro 10 microsecondi dalla serie completa di Fairhead & Bretagnon nel periodo 1600-2200.
  • R3 Fuori dal periodo 1600-2200 solleva ValueError (nessuna estrapolazione oltre la validità dichiarata).

Limiti (che cosa non si afferma)

Termini topocentrici (posizione dell'osservatore), precisione sotto il microsecondo, date fuori dal 1600-2200.

Cancello di rilascio

Calcolato dal registro dai file dei risultati, con la stessa funzione che decide RELEASED.
