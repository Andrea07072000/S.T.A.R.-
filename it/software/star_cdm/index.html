Lettore rigoroso dei Conjunction Data Message CCSDS 508.0-B-1 (KVN) con rapporto di coerenza

Apache-2.0 VERIFIED file singolo

Sintesi

Lettore rigoroso dei Conjunction Data Message CCSDS 508.0-B-1 in formato KVN. Solo libreria standard.

Esegui nel browser

Modifica il codice e premi Esegui (o Ctrl+Invio). Python gira nel tuo browser con il codice pubblicato di questo pacchetto. La prima volta scarica Python una sola volta (circa 12 MB).

Funziona nel browser: tutti i 59 test passano nel Python del browser (Pyodide 314.0.7, Python 3.14.2), misurato il 20 ottobre 2026. 1 test saltato lì: richiede qualcosa che in un browser non c'è (un programma di riferimento esterno o un'estensione non ancora pubblicata).

Usalo sul tuo computer

Non servono account né GitHub. Scarica, poi installa con un comando:

  • File di installazione · star_cdm-0.2.2-py3-none-any.whl 6 kB

Requisiti

  • R1 parse_cdm(text) -> {"header", "object1", "object2", "warnings"}: date come datetime (solo formati CCSDS 502.0), numeri come float, unità controllate rispetto alla norma, esattamente OBJECT1 poi OBJECT2, tutte le parole chiave obbligatorie (l'insieme dell'esempio 3.6.2 della norma).
  • R2 Ogni malformazione solleva CdmFormatError (parola chiave sconosciuta, parola chiave obbligatoria mancante, unità sbagliata, duplicato, valore non numerico, data malformata, numero di oggetti sbagliato). I segni meno tipografici (U+2212) sono normalizzati e SEGNALATI.
  • R3 covariance_rtn(obj) -> 6x6 simmetrica; consistency_report(cdm) confronta MISS_DISTANCE con i vettori di stato e con RELATIVE_POSITION_R/T/N e segnala le incoerenze senza modificare i valori.

Limiti (che cosa non si afferma)

CDM in XML, CDM 2.0 (bozza/aggiornamenti 508.0-B-2), calcolo della probabilità di collisione, qualsiasi uso operativo.
