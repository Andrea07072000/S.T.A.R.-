star-sidereal 0.1.2

Greenwich mean sidereal time (IAU 1982)

Apache-2.0 RELEASED file singolo

La documentazione tecnica del pacchetto è in inglese, come il suo codice.

In parole semplici

GMST and local mean sidereal time, IAU 1982 (Vallado eq. 3-47); verified against Vallado and ERFA.

Provalo qui

Modifica il codice e premi Esegui (o Ctrl+Invio). Python gira nel tuo browser con il codice pubblicato di questo pacchetto. La prima volta scarica Python una sola volta (circa 12 MB).

Usalo sul tuo computer

Non servono account né GitHub. Scarica, poi installa con un comando:

  • File di installazione · star_sidereal-0.1.2-py3-none-any.whl 2 kB
  • File singolo — basta copiarlo accanto al tuo codice · star_sidereal.py 1 kB
  • Codice sorgente (.zip) 11 kB
python -m pip install star_sidereal-0.1.2-py3-none-any.whl

Requisiti

  • R1 gmst82_deg(jd_ut1_day, jd_ut1_frac=0.0) -> degrees in [0, 360), Vallado eq. 3-47 (Aoki et al. 1982).
  • R2 lst_deg(jd_day, jd_frac, east_longitude_deg) -> degrees in [0, 360).
  • R3 Non-finite input raises ValueError. Input is UT1 (not UTC): the caller applies DUT1.
