Requisiti

  • R1 rv_to_coe(r, v, mu=398600.4418) -> (h, e, i, raan, argp, nu) (algoritmo 4.2 di Curtis); unità km, km/s, radianti.
  • R2 coe_to_rv(h, e, i, raan, argp, nu, mu) -> (r, v) (algoritmo 4.5 di Curtis).
  • R3 I casi singolari o non validi sollevano ValueError: equatoriale (nessuna RAAN), circolare (nessun argomento del pericentro), rettilineo, h <= 0, anomalia vera iperbolica oltre gli asintoti. Non viene mai restituito un angolo arbitrario per un elemento non definito.
  • R4 (0.2.0) Anomalie per 0 <= e < 1: mean_to_eccentric (Keplero, Newton; RuntimeError se non converge), eccentric_to_true, true_to_eccentric, eccentric_to_mean; e >= 1 solleva ValueError.
