Orbite e astrodinamica

star-kepler 0.1.1

Propagazione a due corpi con variabili universali

Apache-2.0 RELEASED file singolo

In parole semplici

Propagazione kepleriana con variabili universali e funzioni di Stumpff: nessuna singolarità di geometria orbitale (circolare, equatoriale, ellittica, iperbolica), periodi interi rimossi, radice confinata con iterazioni limitate, rifiuti espliciti.

Provalo qui

Modifica il codice e premi Esegui (o Ctrl+Invio). Python gira nel tuo browser con il codice pubblicato di questo pacchetto. La prima volta scarica Python una sola volta (circa 12 MB).

Usalo sul tuo computer

Non servono account né GitHub. Scarica, poi installa con un comando:

  • File di installazione · star_kepler-0.1.1-py3-none-any.whl 4 kB
  • File singolo — basta copiarlo accanto al tuo codice · star_kepler.py 7 kB
  • Codice sorgente (.zip) 19 kB
python -m pip install star_kepler-0.1.1-py3-none-any.whl

Requisiti

  • R1 propagate restituisce posizione e velocità per orbite ellittiche e iperboliche, in qualunque unità coerente; riproduce l'esempio 2-4 di Vallado entro la precisione stampata (1e-3 km, 1e-5 km/s).
  • R2 Nessuna singolarità di geometria orbitale: orbite circolari ed equatoriali sono propagate come le altre; sulle orbite chiuse i periodi interi sono rimossi, quindi mille rivoluzioni riportano lo stato iniziale entro 1e-4 km.
  • R3 Accuratezza: su 450 orbite note (eccentricità da 0 a 0,95, 0 e 10 rivoluzioni) l'errore è sotto 1e-6 km (1 mm) e 1e-8 km/s; energia e momento angolare si conservano entro 1e-9 relativo.
  • R4 Comportamento in caso di errore: ingressi non finiti, posizione nulla, mu <= 0, lunghezza del vettore sbagliata e moto rettilineo sollevano ValueError prima di qualunque iterazione; un budget di iterazioni esaurito solleva RuntimeError; la chiamata non può ciclare all'infinito (radice confinata, bisezione limitata).

Limiti (che cosa non si afferma)

Solo moto a due corpi (nessuna perturbazione). Le orbite paraboliche usano la stessa serie ma non sono validate separatamente. Le orbite rettilinee sono rifiutate. Nessuna esperienza di volo.
