conjunction-screen-sgp4 0.2.1

Conjunction screening of TLE catalogues with SGP4, KD-tree coarse pass and closed-form TCA refinement

Apache-2.0 RELEASED

La documentazione tecnica del pacchetto è in inglese, come il suo codice.

In parole semplici

Screening of close approaches between objects of TLE catalogues (who to look at), NOT a collision-probability tool.

Provalo qui

Modifica il codice e premi Esegui (o Ctrl+Invio). Python gira nel tuo browser con il codice pubblicato di questo pacchetto. La prima volta scarica Python una sola volta (circa 12 MB).

Questo pacchetto richiede numpy, scipy, sgp4, che qui non è disponibile nel browser. Usalo sul tuo computer.

Usalo sul tuo computer

Non servono account né GitHub. Scarica, poi installa con un comando:

  • File di installazione · conjunction_screen_sgp4-0.2.1-py3-none-any.whl 7 kB
  • Codice sorgente (.zip) 70 kB
python -m pip install conjunction_screen_sgp4-0.2.1-py3-none-any.whl      # numpy, scipy, sgp4 from the internet

Requisiti

  • R1 screen(tle_paths, start, hours, step, coarse_km, final_km, cross_only, refine) returns encounters (TCA in UTC, miss distance km, age of the older TLE) below final_km, excluding pairs that stay close (formations).
  • R2 TLEs are propagated with SGP4 only (mean elements); propagation errors are reported, never replaced.
  • R3 refine_tca(state_at, step): closed-form TCA from relative motion, shared by screening and tests.
