conjunction-screen-sgp4 0.2.1

Screening delle congiunzioni su cataloghi TLE con SGP4, passaggio grossolano con KD-tree e raffinamento del TCA in forma chiusa

Apache-2.0 VERIFIED

In parole semplici

Screening degli avvicinamenti ravvicinati tra oggetti di cataloghi TLE (quali oggetti guardare), NON uno strumento per la probabilità di collisione.

Provalo qui

Modifica il codice e premi Esegui (o Ctrl+Invio). Python gira nel tuo browser con il codice pubblicato di questo pacchetto. La prima volta scarica Python una sola volta (circa 12 MB).

Questo pacchetto richiede numpy, scipy, sgp4, che qui non è disponibile nel browser. Usalo sul tuo computer.

Usalo sul tuo computer

Non servono account né GitHub. Scarica, poi installa con un comando:

  • File di installazione · conjunction_screen_sgp4-0.2.1-py3-none-any.whl 7 kB
  • Codice sorgente (.zip) 70 kB
python -m pip install conjunction_screen_sgp4-0.2.1-py3-none-any.whl      # numpy, scipy, sgp4 from the internet

Requisiti

  • R1 screen(tle_paths, start, hours, step, coarse_km, final_km, cross_only, refine) restituisce gli incontri (TCA in UTC, distanza minima in km, età del TLE più vecchio) sotto final_km, escludendo le coppie che restano vicine (formazioni).
  • R2 I TLE sono propagati solo con SGP4 (elementi medi); gli errori di propagazione sono riportati, mai sostituiti.
  • R3 refine_tca(state_at, step): TCA in forma chiusa dal moto relativo, condiviso da screening e test.
