Orbite e astrodinamica

star-tle 0.1.0

Un lettore rigoroso dei set di elementi a due righe

Apache-2.0 RELEASED file singolo

In parole semplici

Legge ogni campo di un set di elementi NORAD a due righe così come è stampato (Alpha-5 incluso) e rifiuta i set malformati con un motivo leggibile da una macchina; campi uguali a python-sgp4 e Orekit entro 6e-14, e più rigoroso di entrambi sugli ingressi malformati.

Provalo qui

Modifica il codice e premi Esegui (o Ctrl+Invio). Python gira nel tuo browser con il codice pubblicato di questo pacchetto. La prima volta scarica Python una sola volta (circa 12 MB).

Funziona nel browser: tutti i 112 test passano nel Python del browser (Pyodide 314.0.7, Python 3.14.2), misurato il 20 ottobre 2026.

Usalo sul tuo computer

Non servono account né GitHub. Scarica, poi installa con un comando:

  • File di installazione · star_tle-0.1.0-py3-none-any.whl 4 kB
  • File singolo — basta copiarlo accanto al tuo codice · star_tle.py 7 kB
  • Codice sorgente (.zip) 24 kB
python -m pip install star_tle-0.1.0-py3-none-any.whl

Requisiti

  • R1 parse(line1, line2): numero di catalogo (Alpha-5 incluso), classificazione, designatore internazionale, epoca (anno a quattro cifre con la finestra 1957-2056, giorno dell'anno), metà della derivata prima e un sesto della derivata seconda del moto medio, B*, tipo di effemeride, numero di elemento, inclinazione, ascensione retta del nodo, eccentricità, argomento del perigeo, anomalia media, moto medio, numero di rivoluzione. Ogni numero è il double più vicino al testo stampato.
  • R2 checksum(line): le cifre contano per sé, '-' conta 1, tutto il resto 0, modulo 10. epoch_utc(tle).
  • R3 Misurato sui 29 set ben formati del catalogo di verifica SGP4: tutti i 14 campi numerici uguali a python-sgp4 e a Orekit entro 6e-14 dopo la conversione delle unità.
  • R4 Un set malformato solleva TleError (un ValueError) il cui reason è uno di: length, charset, line_number, checksum, satnum_mismatch, field:<name>, range:<name>. Nulla viene riparato. Misurato su 174 set malformati di sei tipi: star_tle ne rifiuta 147, Orekit 145, python-sgp4 nessuno (è tollerante per scelta). I due rifiuti in più sono set con checksum corretto il cui angolo del nodo o del perigeo è di 360 gradi o più.

Limiti (che cosa non si afferma)

Un lettore, non un propagatore: gli elementi sono elementi medi SGP4 nel sistema TEME e non significano nulla senza SGP4. Niente set a tre righe (riga del nome), niente OMM/XML/JSON, nessuno scrittore. Il rigore è una scelta: un set che un altro strumento accetta può essere rifiutato qui, con il motivo.
