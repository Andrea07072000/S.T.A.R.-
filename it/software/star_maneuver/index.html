star-maneuver 0.2.2

Vis-viva e trasferimento di Hohmann in forma chiusa

Apache-2.0 VERIFIED file singolo

In parole semplici

Calcolo delle manovre impulsive tra orbite circolari complanari e dei cambi di piano. Solo libreria standard.

Provalo qui

Modifica il codice e premi Esegui (o Ctrl+Invio). Python gira nel tuo browser con il codice pubblicato di questo pacchetto. La prima volta scarica Python una sola volta (circa 12 MB).

Funziona nel browser: tutti i 68 test passano nel Python del browser (Pyodide 314.0.7, Python 3.14.2), misurato il 20 ottobre 2026.

Usalo sul tuo computer

Non servono account né GitHub. Scarica, poi installa con un comando:

  • File di installazione · star_maneuver-0.2.2-py3-none-any.whl 2 kB
  • File singolo — basta copiarlo accanto al tuo codice · star_maneuver.py 3 kB
  • Codice sorgente (.zip) 15 kB
python -m pip install star_maneuver-0.2.2-py3-none-any.whl

Requisiti

  • R1 vis_viva(r, a, mu); hohmann(r1, r2, mu) e bielliptic(r1, r2, rb, mu) restituiscono il delta-v per accensione e totale (km/s) e il tempo di volo (s). Unità: km, s, km/s, km^3/s^2 (mu predefinito = 398600,4418, IERS Conventions 2010).
  • R2 plane_change(v, di) = 2 v sin(di/2); combined_dv(v1, v2, di) con il teorema del coseno (radianti).
  • R3 Gli ingressi non validi falliscono esplicitamente con ValueError (raggi non positivi, rb < max(r1, r2), velocità negativa).

Limiti (che cosa non si afferma)

Accensioni finite, perdite gravitazionali, Hohmann non complanare con ripartizione ottima del cambio di piano, qualsiasi qualifica al volo.
