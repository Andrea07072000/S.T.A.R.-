star-crosscheck 0.1.3

Struttura di verifica tra risolutori diversi (S.T.A.R.)

Apache-2.0 RELEASED

In parole semplici

Esegue motori di lignaggio dichiarato (ciascuno eventualmente nel proprio ambiente virtuale) sugli stessi dati; AGREE solo con almeno 2 lignaggi distinti entro la tolleranza, i motori falliti non contano mai, i riferimenti pubblicati sono confrontati; pacchetti di evidenza con sha256 che rendono evidente ogni manomissione.

Provalo qui

Modifica il codice e premi Esegui (o Ctrl+Invio). Python gira nel tuo browser con il codice pubblicato di questo pacchetto. La prima volta scarica Python una sola volta (circa 12 MB).

Usalo sul tuo computer

Non servono account né GitHub. Scarica, poi installa con un comando:

  • File di installazione · star_crosscheck-0.1.3-py3-none-any.whl 7 kB
  • Codice sorgente (.zip) 72 kB
python -m pip install star_crosscheck-0.1.3-py3-none-any.whl

Requisiti

  • R1 crosscheck(quantity, inputs, engines, tolerance, ...) esegue ogni motore (eventualmente nel proprio ambiente virtuale tramite sottoprocesso + JSON) e restituisce un verdetto: AGREE solo se almeno due lignaggi DISTINTI concordano entro la tolleranza.
  • R2 Motori dello stesso lignaggio contano come UN solo testimone (INSUFFICIENT_INDEPENDENCE quando restano meno di due lignaggi).
  • R3 Un motore fallito non conta mai come accordo: verdetto DEGRADED, con l'errore registrato.
  • R4 Riferimento pubblicato facoltativo: ogni motore è confrontato anche con esso.
  • R5 Ogni risultato è un pacchetto di evidenza con uno sha256 sul suo contenuto (tempi esclusi), che rende evidente ogni manomissione.
