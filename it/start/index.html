Come iniziare

Tre modi per usare il software S.T.A.R. Scegli quello adatto a te; nessuno richiede un account, e solo il terzo richiede GitHub.

1

Provalo qui, nel browser

Apri la pagina di un pacchetto e premi Esegui. Un vero Python gira nel tuo browser con il codice pubblicato del pacchetto: niente da installare, nulla inviato altrove.

Scegli un pacchetto
2

Usalo sul tuo computer

Scarica il pacchetto e installalo con un comando, anche senza internet. Funziona su Windows, macOS e Linux con Python 3.9 o successivo. I pacchetti di un solo file si possono semplicemente copiare accanto al tuo codice.

Download
3

Per sviluppatori

Installa direttamente dal repository pubblico con pip, leggi sorgente, test ed evidenze e riproduci le campagne.

Repository pubblico

Usarlo sul tuo computer, passo per passo

  1. Installa Python
    Se non ce l'hai: scarica Python 3.9 o successivo da python.org (su Windows spunta «Add python.exe to PATH» durante l'installazione). macOS e la maggior parte dei sistemi Linux lo hanno già.
  2. Scarica il pacchetto
    Nella pagina del pacchetto, in «Usalo sul tuo computer», scarica il file .whl (oppure l'intera raccolta da Download).
  3. Apri un terminale nella cartella dei download
    Windows: nella cartella scrivi cmd nella barra dell'indirizzo e premi Invio. macOS: clic destro sulla cartella → Nuovo terminale nella cartella. Linux: clic destro → Apri nel terminale.
  4. Installa
    Scrivi: python -m pip install <il file scaricato>.whl — per esempio python -m pip install star_kepler-0.1.1-py3-none-any.whl
  5. Usalo
    Avvia python e importa il pacchetto, come nell'esempio della sua pagina.

Senza installare nulla

I pacchetti fatti di un solo file e senza dipendenze (indicati come «file singolo») si usano scaricando quel file .py e mettendolo nella stessa cartella del tuo programma. Funziona poi con import, come ogni tuo file.

Altre macchine e ambienti di compilazione

I file .whl sono Python puro (py3-none-any): lo stesso file si installa su qualunque sistema operativo e processore. Per una macchina senza rete copia l'archivio della raccolta e installa con --no-index. Per un tuo sistema di compilazione o di pacchettizzazione usa il sorgente .zip di ciascun pacchetto. Ogni file ha un'impronta SHA-256 pubblicata.
